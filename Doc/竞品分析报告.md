# NewLife.Siemens 竞品分析报告

## 1. 概述

本报告对比 **NewLife.Siemens** 与市面上主流的西门子 S7 协议通信库，从功能覆盖、架构设计、许可证、框架兼容性、维护活跃度等维度进行综合评估，为后续功能规划提供需求第二来源。

**项目愿景**（摘自 `Doc/需求文档.md`）：提供工业物联网领域**最完整、最易用的西门子 PLC S7 协议 .NET 实现**，作为 NewLife IoT 标准驱动组件，让工控工程师用几行代码接入任意西门子 PLC，同时支持 IoTEdge 网关零代码配置化采集。

**对比范围**：开源 S7 协议库（S7netplus、Sharp7）为主，兼顾多协议工业通信套件（HslCommunication）及西门子官方库（S7 Web API），商业竞品（Kepware、OPC Server）仅作定性提及。

## 5. API 易用性对比

以「读取 DB1.DBW0 一个 Int16 值」为例，对比各库代码量：

### NewLife.Siemens
```csharp
var client = new S7Client(CpuType.S71200, "192.168.1.100");
await client.OpenAsync();
var value = client.Read<Int16>("DB1.DBW0");  // 1 行搞定
```

### S7netplus
```csharp
var plc = new Plc(CpuType.S71200, "192.168.1.100", 0, 0);
plc.Open();
var value = (short)plc.Read("DB1.DBW0");     // 需手动转型
plc.Close();
```

### Sharp7
```csharp
var client = new S7Client();
client.ConnectTo("192.168.1.100", 0, 0);
var buffer = new byte[2];
client.DBRead(1, 0, 2, buffer);             // 需手动处理 DB 号+偏移
var value = S7.GetShortAt(buffer, 0);        // 需手动字节序转换
```

### HslCommunication
```csharp
var siemens = new SiemensS7Net(SiemensPLCS.S1200, "192.168.1.100");
var result = siemens.ReadInt16("DB1.DBW0");  // OperateResult<T> 包裹
if (result.IsSuccess) var value = result.Content;
```

| 维度 | NewLife.Siemens | S7netplus | Sharp7 | HslComm |
|------|:---:|:---:|:---:|:---:|
| 代码行数 | 3 行 | 4 行 | 5 行 | 5 行 |
| 地址格式 | 字符串 | 字符串 | 手动拆 DB+偏移 | 字符串 |
| 返回类型 | 强类型 T | Object（需转型） | Byte[]（需手动解析） | OperateResult\<T\> |
| 自动字节序 | ✅ | ✅ | ❌ | ✅ |
| 异步支持 | ✅ (OpenAsync) | ❌ (同步 Open) | ❌ | ❌ |

## 7. 结论与建议

### 竞争定位

NewLife.Siemens 在 **S7 协议专用库**赛道上功能已全面领先：

```
功能完整度：NewLife.Siemens >> S7netplus > Sharp7
IoT 集成度：NewLife.Siemens（唯一）
社区规模：  S7netplus >> HslCommunication >> NewLife.Siemens
```

**差异化护城河**：IoTEdge 集成 + S7Server 模拟器 + ReadStruct，三者均为竞品空白，构成不可替代的技术壁垒。

### 行动建议

| 优先级 | 行动 | 预期收益 |
|--------|------|---------|
| 🔴 **高** | 补充 GTM 支持 | 消除与 S7netplus 的最后一个功能盲区 |
| 🔴 **高** | 英文 README + Wiki + 快速入门视频 | 缩小社区差距，提升海外采纳 |
| 🟡 **中** | 补充密码保护连接 | 覆盖安全合规场景 |
| 🟢 **低** | BenchmarkDotNet 性能基准 + 覆盖率徽章 | 提升专业可信度 |

### 商业竞品参考

工业领域西门子 PLC 连接还有以下商业方案，按成本从低到高：

| 方案 | 模式 | 适用场景 |
|------|------|---------|
| OPC UA Server（PLC 内置） | S7-1500 内置 OPC UA | 标准化数据交换，需硬件支持 |
| Kepware KEPServerEX | 商业 OPC Server | 多协议集中采集，价格 $1K~$10K |
| Siemens WinCC / TIA Portal | 西门子官方上位机 | SCADA 系统，价格高 |

> 本项目的直接竞品是**开源/低成本 S7 协议库**，上述商业方案是替代技术路径而非直接竞品。
